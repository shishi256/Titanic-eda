# Titanic Dataset - Exploratory Data Analysis
## About the Project

I used the Titanic dataset to explore the factors that were related
to passenger survival. I cleaned the dataset, created a few useful
features and used different charts to understand the patterns.

## Dataset

Dataset used:
https://www.kaggle.com/c/titanic/data

## What I Did

- Checked the dataset structure and missing values
- Cleaned the Age column
- Removed duplicate records
- Created FamilySize and IsAlone features
- Created AgeGroup
- Compared survival by passenger class and gender
- Created an age distribution histogram
- Created a correlation heatmap

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- JupyterLab

## Project Files

- `Titanic_EDA.ipynb` - Main analysis notebook
- `data/titanic.csv` - Original dataset
- `data/titanic_cleaned.csv` - Cleaned dataset
- `charts/` - Exported charts

## Conclusion

The analysis showed noticeable differences in survival based on
passenger class and gender. Age and family size also helped provide
more context to the results. Overall, cleaning and visualizing the
data made the main survival patterns easier to understand.
